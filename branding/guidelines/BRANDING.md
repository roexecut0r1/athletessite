## Typography
- **Headings:** Inter Bold / Extra Bold
- **Body:** Inter Regular
- **Monospace:** Fira Code / JetBrains Mono
- **Fallback:** system sans-serif

## Logo
- Star-shaped mark in hot pink (#FF1493)
- Simple, recognizable at small sizes
- Used with glow effect on dark backgrounds
- Keep clear space of at least 1x logo width around mark

## Visual Principles
1. **Glamorous but usable** — flashy ≠ unusable
2. **Dark backgrounds** — deep purple-black, never pure black
3. **Pink accents** — hot pink as primary interactive color
4. **Glassmorphism** — frosted glass panels with purple tint
5. **Sparkles** — used tastefully, never overwhelming (except Classic mode)
6. **Gradients** — pink→purple directional gradients for emphasis
7. **Glow effects** — subtle neon glow on interactive elements

## Modes

### Classic HML
- Maximum sparkles and glitter
- Bright pink UI elements
- Louder, more prominent effects
- Nostalgia-first design

### Modern HML (Default)
- Clean, refined aesthetic
- Subtle sparkles
- Professional enough for daily use
- Pink/purple accents without overwhelming

### Dark Glam
- Near-black backgrounds
- Neon pink/purple accent lines
- RGB gamer aesthetic
- Minimal sparkles, maximum contrast

## Voice & Tone
- Playful and fun, but not childish
- Nostalgic without being stuck in the past
- Confident and glamorous
- Encouraging and inclusive
- Use sparkle emoji ✨ in UI copy where appropriate
