# ✨ HML Reimagined — Implementation Roadmap & Guide

## Overview
This document provides the step-by-step implementation roadmap for building
HML Reimagined from source. Each phase is designed to be independently
completable and testable.

---

## Phase 1: Core Distro Setup (Week 1-2)

### 1.1 Development Environment
```bash
# Set up on Ubuntu 24.04 LTS (VM or bare metal)
sudo apt update && sudo apt upgrade -y
sudo apt install -y git build-essential

# Clone the project
git clone https://github.com/hml-reimagined/hml-reimagined.git
cd hml-reimagined

# Install build dependencies
sudo apt install -y \
    xorriso squashfs-tools genisoimage wget rsync \
    grub-efi-amd64-bin grub-efi-amd64-signed shim-signed \
    python3-pil sox fonts-inter fonts-dejavu \
    qemu-system-x86 ovmf
```

### 1.2 Obtain Base ISO
```bash
# Download Kubuntu 24.04.2 LTS
wget https://cdimage.ubuntu.com/kubuntu/releases/24.04.2/release/kubuntu-24.04.2-desktop-amd64.iso
```

### 1.3 First Cubic Test Run
```bash
# Install Cubic
sudo apt-add-repository ppa:cubic-wizard/release
sudo apt update && sudo apt install cubic

# Launch and select Kubuntu ISO
# Test basic customization: install neofetch, change wallpaper
# Build test ISO and verify it boots in QEMU
sudo bash build-scripts/test-qemu.sh output/test.iso
```

### 1.4 Verify UEFI Boot
- Test ISO boots in QEMU with OVMF
- Test with VirtualBox EFI mode
- Verify GPT partition table is created
- Verify EFI System Partition is created
- Test dual-boot detection with Windows 11

## Phase 5: Packaging & ISO Generation (Week 6-7)

### 5.1 Build Debian Packages
```bash
chmod +x packaging/build-debs.sh
sudo bash packaging/build-debs.sh
# Output: output/debs/*.deb
```

### 5.2 Build Full ISO
```bash
chmod +x build-scripts/build-iso.sh
sudo bash build-scripts/build-iso.sh
# Output: output/HML-Reimagined-1.0-amd64.iso
```

### 5.3 Alternative: Cubic Workflow
1. Launch Cubic GUI
2. Select Kubuntu 24.04.2 ISO as base
3. In chroot terminal, run:
   ```bash
   bash /path/to/build-scripts/cubic-chroot.sh
   ```
4. Exit chroot and build ISO

cd hml-reimagined
git init

## Hardware Compatibility Matrix

| Hardware                     | Status    | Notes                           |
|-----------------------------|-----------|---------------------------------|
| HP Pavilion/Envy/x360       | Primary   | UEFI-only, tested               |
| Intel modern laptops        | Primary   | Full support via linux-firmware  |
| AMD Ryzen laptops           | Primary   | Full support                    |
| Intel/NVIDIA hybrid         | Supported | ubuntu-drivers helper included  |
| AMD/NVIDIA hybrid           | Supported | Via PRIME render offload         |
| NVMe SSDs                   | Required  | Kernel drivers in initramfs      |
| Modern Wi-Fi (Intel AX200+) | Supported | linux-firmware package           |
| Touchpad/Touchscreen        | Supported | libinput, KDE Wayland gestures   |
| HiDPI/4K displays           | Supported | KDE fractional scaling           |
| Thunderbolt docks           | Supported | bolt package included            |
